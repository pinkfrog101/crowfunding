# Crowd Funding Application

A Spring Boot application for managing crowdfunding projects and investments, featuring structured data handling with JPA.

## Features

- Create and manage crowdfunding projects
- Make investments in projects
- Track funding progress
- RESTful API endpoints
- JPA entity relationships

## Tech Stack

- Java, Spring Boot
- Spring Data JPA, Hibernate
- Maven

## How to Run

```bash
git clone https://github.com/balaganesh55/project-and-investment.git
cd project-and-investment/crowdFundingApplication
./mvnw spring-boot:run
```
